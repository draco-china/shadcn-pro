## Prerequisites

Before installing shadcn-pro, make sure you have:

- **Node.js 18+** (or Bun / pnpm)
- A Next.js project (or any React framework) with **shadcn/ui already initialized**

<Callout>
  If you haven't set up shadcn/ui yet, follow the [shadcn/ui installation guide](https://ui.shadcn.com/docs/installation) first, then come back here.
</Callout>

## Install a Component

shadcn-pro is distributed as a public shadcn registry. There is no npm package to install and no GitHub Packages authentication step.

Add components with the official shadcn CLI:

```bash
npx shadcn@latest add https://draco-china.github.io/shadcn-pro/r/pro-form.json
```

This copies the component source code directly into your project under `components/pro/`.

For example:

```bash
bun add class-variance-authority hast-util-to-jsx-runtime lucide-react
```

### 2. Copy the component

Browse the component source on GitHub and copy each component folder into your project. Prefer the registry installer because it also copies shared Pro dependencies such as `pro-base`.

- `ProBase` → `components/pro/base/`
- `ProFields` → `components/pro/base/fields/`
- `ProForm` → `components/pro/form/`
- `ProTable` → `components/pro/table/`
- `ProEditor` → `components/pro/editor/`
- `ProDescriptions` → `components/pro/descriptions/`
- `CodeViewer` → `components/pro/viewer/code/`
- `DiffViewer` → `components/pro/viewer/diff/`
- `HtmlViewer` → `components/pro/viewer/html/`
- `ImageViewer` → `components/pro/viewer/image/`
- `MarkdownViewer` → `components/pro/viewer/markdown/index.tsx` and `components/pro/viewer/code/`

## Standard Patterns

### Request + hooks/store

Use `request` to keep existing API hooks or stores outside the table component while still letting ProTable own pagination, filters, and sorting.

```tsx
<ProTable
  columns={columns}
  rowKey="id"
  request={({ pagination, sorting, columnFilters }) =>
    userStore.fetchUsers({
      page: pagination.pageIndex + 1,
      pageSize: pagination.pageSize,
      sort: sorting[0]?.id,
      order: sorting[0] ? (sorting[0].desc ? "desc" : "asc") : undefined,
      filters: columnFilters,
    })
  }
/>
```

The request result should be `{ data, total }`.

### URL state

```tsx
const tableState = useProTableUrlState({
  search,
  navigate,
  sorting: { sortKey: "sort", orderKey: "order" },
  columnFilters: [
    { columnId: "name", searchKey: "name" },
    { columnId: "role", searchKey: "role", type: "array" },
  ],
})

<ProTable columns={columns} rowKey="id" request={request} {...tableState} />
```

### Schema forms

```tsx
<ProForm
  onFinish={saveValues}
  schema={[
    { name: "name", label: "Name", required: true },
    {
      name: "role",
      label: "Role",
      valueType: "select",
      fieldProps: { options: roleOptions },
    },
  ]}
/>
```

Use schema for common forms, and use `formRef` when a page needs imperative form control. `ModalForm` and `DrawerForm` can be controlled with `open` / `onOpenChange` without a trigger, while reusable modal, drawer, and confirm shells live in `pro-overlay`.

## TypeScript

shadcn-pro is written in TypeScript. All components are fully typed.

## Tailwind CSS

shadcn-pro uses Tailwind CSS v4 classes and inherits your shadcn/ui theme tokens. No additional configuration is needed.
