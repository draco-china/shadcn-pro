## Usage

```tsx
import { Copy, RefreshCw } from "lucide-react"
import { CopyButton } from "@/components/pro/base/button/copy"
import { FullscreenButton } from "@/components/pro/base/button/fullscreen"
import { RefreshButton } from "@/components/pro/base/button/refresh"
import { TooltipButton } from "@/components/pro/base/button/tooltip"

<CopyButton
  prefix={<Copy />}
  tooltip="Copy link"
  copy={{
    text: () => window.location.href,
    success: "Copied",
    error: "Copy failed",
  }}
/>

<FullscreenButton fullscreen={{ value: false }} />
```

`ProButton` owns the shadcn-compatible button variants and adds prefix, suffix, and loading slots without taking over action logic. `TooltipButton` adds tooltip composition, `CopyButton` adds copy feedback, `RefreshButton` standardizes refresh actions, and `FullscreenButton` standardizes fullscreen toggle presentation on top of it. Copy success temporarily changes the prefix to a green check; failed copy shows an error prefix and tooltip.

`useFullscreen` lives in `base/hooks/use-fullscreen` and centralizes controlled/uncontrolled fullscreen behavior for components such as editors, viewers, previews, and panels.

## Examples

### Async Action

```tsx
<RefreshButton tooltip="Refresh" loading={isRefreshing} onClick={() => refresh()}>
  Refresh
</RefreshButton>
```

`ProButton` and `RefreshButton` do not manage async click state. Pass `loading` explicitly when an action is pending.

### Copy

```tsx
<CopyButton
  prefix={<Copy />}
  tooltip="Copy API key"
  copy={{
    text: apiKey,
    success: "Copied",
    error: "Copy failed",
  }}
/>
```

### Fullscreen

```tsx
import { FullscreenButton } from "@/components/pro/base/button/fullscreen"
import { useFullscreen } from "@/components/pro/base/hooks/use-fullscreen"

function PreviewPanel() {
  const {
    ref,
    fullscreen,
    isFixedFullscreen,
    isScreenFullscreen,
    setFullscreen,
  } = useFullscreen<HTMLDivElement>({
    mode: "screen",
  })

  return (
    <div ref={ref}>
      <FullscreenButton fullscreen={{ value: fullscreen, onChange: setFullscreen }} />
      <div>{isFixedFullscreen || isScreenFullscreen ? "Fullscreen" : "Inline"}</div>
    </div>
  )
}
```

## API Reference

### ProButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `prefix` | `ReactNode` | — | Optional leading content. |
| `suffix` | `ReactNode` | — | Optional trailing content. |
| `loading` | `boolean` | `false` | Forces loading state. |
| `disabled` | `boolean` | `false` | Disables the button. Loading also disables it. |
| `onClick` | `(event) => void` | — | Native click handler. Async state is controlled by passing `loading`. |
| `type` | `'button' \| 'submit' \| 'reset'` | `'button'` | Native button type. Defaults to `button` to avoid accidental form submission. |
| `children` | `ReactNode` | — | Button label/content. |

Other button HTML props are passed to the rendered button or slot child.

### TooltipButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tooltip` | `ReactNode` | — | Tooltip content. If omitted, only `ProButton` is rendered. |
| `aria-label` | `string` | tooltip text | Accessible label. String tooltip content is used as a fallback. |

`TooltipButton` also accepts `ProButton` props.

### CopyButton

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `copy` | `{ text, success?, error?, resetDuration?, onSuccess?, onError? }` | — | Copy configuration. `text` can be a string or async function. |
| `tooltip` | `ReactNode` | — | Default tooltip before feedback state is shown. |

`CopyButton` also accepts `TooltipButton` props.

### useFullscreen

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `fullscreen` | `boolean` | — | Controlled fullscreen state. |
| `defaultFullscreen` | `boolean` | `false` | Initial uncontrolled fullscreen state. |
| `onFullscreenChange` | `(fullscreen: boolean) => void` | — | Called when fullscreen state changes. |
| `mode` | `'fixed' \| 'screen'` | `'fixed'` | Fixed-position simulated fullscreen or browser Fullscreen API. |
| `ref` | `RefObject<HTMLElement>` | internal ref | Optional target element ref. |

**Returns:**

| Key | Type | Description |
| --- | --- | --- |
| `ref` | `RefObject<HTMLElement>` | Ref to attach to the fullscreen target. |
| `fullscreen` | `boolean` | Current fullscreen state. |
| `fullscreenMode` | `'fixed' \| 'screen'` | Active fullscreen mode. |
| `isFixedFullscreen` | `boolean` | `true` when fullscreen is active in fixed mode. |
| `isScreenFullscreen` | `boolean` | `true` when fullscreen is active through the browser Fullscreen API. |
| `setFullscreen` | `(fullscreen: boolean) => void` | Updates fullscreen state. |
| `toggleFullscreen` | `() => void` | Toggles fullscreen state. |
