## Usage

```tsx
import { ProConfirm, ProDrawer, ProModal } from "@/components/pro/overlay"

<ProModal trigger={<button type="button">Open</button>} title="Preview">
  Content
</ProModal>

<ProDrawer trigger={<button type="button">Details</button>} title="Details">
  Content
</ProDrawer>

<ProConfirm
  trigger={<button type="button">Delete</button>}
  title="Delete record?"
  description="This action cannot be undone."
  confirmText="Delete"
  onConfirm={remove}
/>
```

`ProModal` and `ProDrawer` own only the overlay shell. Use `ProConfirm` for ordinary confirmation flows, and put forms, filters, panels, custom content, and action buttons inside modal or drawer shells at the call site.
