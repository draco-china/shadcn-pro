## Usage

Every field is a plain React/shadcn component. Simple fields preserve the underlying shadcn/ui prop surface where practical; shadcn-pro adds only small behaviors such as clear actions, affix slots, and options mapping. Compose section layouts at the call site.

`Input` only applies the default horizontal padding when no affix is present. When `prefix` or `suffix` is provided, the shell keeps the slot flush and the passed content owns its own spacing, such as `px-3` on a currency prefix.

### ArrayField

Drag-to-reorder list with built-in state management. Supports controlled (`value` + `onChange`) and uncontrolled (`defaultValue`) usage.

<ComponentPreview
  name="pro-fields-array-field-demo"
  previewClassName="min-h-[280px] items-start p-6"
  align="start"
/>

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `TItem[]` | — | Controlled array value |
| `onChange` | `(value: TItem[]) => void` | — | Called on any change |
| `defaultValue` | `TItem[]` | `[]` | Initial value (uncontrolled) |
| `newItem` | `() => TItem` | — | Factory for blank items |
| `renderItem` | `(item, index, helpers) => ReactNode` | — | Render each item. `helpers.update` accepts a replacement value or updater function; `helpers.duplicate` copies the row; `helpers.remove` removes it. |
| `max` | `number` | — | Hide Add button when reached |
| `min` | `number` | `0` | Hide Remove button when at minimum |
| `disabled` | `boolean` | `false` | Disables all controls |
