## Usage

```tsx
import { ProForm } from "@/components/pro/form"

const roleOptions = [
  { label: "Admin", value: "admin" },
  { label: "Editor", value: "editor" },
  { label: "Viewer", value: "viewer" },
]

export function AccountForm() {
  return (
    <ProForm
      onFinish={async (values) => console.log(values)}
      schema={[
        { name: "name", label: "Name", required: true, fieldProps: { placeholder: "Alice Wang" } },
        {
          name: "email",
          label: "Email",
          valueType: "email",
          required: true,
          fieldProps: { placeholder: "alice@example.com" },
        },
        {
          name: "role",
          label: "Role",
          valueType: "select",
          fieldProps: { placeholder: "Select role", options: roleOptions },
        },
      ]}
    />
  )
}
```

`ProForm` manages TanStack Form internally. Schema items only describe how fields render; values and validation flow through `form.Field` and `form.handleSubmit`.

For custom layout, put fields inside `FormItem`. When `name` is set, `FormItem` binds the child control to the internal form.

```tsx
import { Input } from "@/components/pro/base/fields/input"
import { FormItem, ProForm } from "@/components/pro/form"

type Values = { name: string; role?: string }

export function AccountForm() {
  return (
    <ProForm<Values> defaultValues={{ name: "" }} onFinish={async (values) => console.log(values)}>
      <FormItem
        label="Name"
        name="name"
        required
        validators={{
          onBlur: ({ value }) =>
            typeof value === "string" && value.length < 2
              ? "Name must be at least 2 characters."
              : undefined,
        }}
      >
        <Input placeholder="Alice Wang" />
      </FormItem>
    </ProForm>
  )
}
```

Use `formRef` when a page needs imperative access to the internal form instance.

Pass a Zod schema directly to `validator`. TanStack Form supports Standard Schema without an adapter.

```tsx
import { z } from "zod"
import { ProForm } from "@/components/pro/form"

const formSchema = z.object({
  email: z.string().email("Enter a valid email address."),
  password: z.string().min(8, "Password must be at least 8 characters."),
})

type Values = z.infer<typeof formSchema>

export function AccountForm() {
  return (
    <ProForm<Values>
      validator={formSchema}
      defaultValues={{ email: "", password: "" }}
      onFinish={async (values) => console.log(values)}
      schema={[
        { name: "email", label: "Email", valueType: "email", required: true },
        { name: "password", label: "Password", valueType: "password", required: true },
      ]}
    />
  )
}
```

## Submitter

The default submitter renders a submit button. Pass `submitter={false}` to hide it, or pass a React node / render function when the footer needs custom buttons.

```tsx
import { ProButton } from "@/components/pro/base/button"

<ProForm
  submitter={({ submitting, reset }) => (
    <>
      <ProButton type="button" variant="secondary" disabled={submitting} onClick={reset}>
        Reset
      </ProButton>
      <ProButton type="submit" loading={submitting} disabled={submitting}>
        {submitting ? "Submitting..." : "Submit"}
      </ProButton>
    </>
  )}
/>
```

## ModalForm

<ComponentPreview name="pro-form-modal-demo" />

`ModalForm` wraps the same composed form body in a Dialog and closes after `onFinish` resolves. It also accepts the same `schema` and `defaultValues` props as `ProForm`.

## API

### ProForm

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | — | Form fields and layout sections. |
| `schema` | `Array<{ name: string; valueType?: string; ... }>` | — | Optional field definitions rendered with ProFields. |
| `formRef` | `Ref<ProFormInstance<T>>` | — | Imperative access to the internal form instance. |
| `validator` | `FormValidateOrFn<T>` | — | TanStack Form submit validator; accepts Standard Schema such as Zod directly. |
| `defaultValues` | `T` | — | Initial values used by the internal form. |
| `onFinish` | `(values) => void \| Promise<void>` | — | Called by `form.handleSubmit` with validated values. |
| `onFinishFailed` | `(error) => void` | — | Called with validation errors or errors thrown by `onFinish`. |
| `onReset` | `() => void \| Promise<void>` | — | Called after `form.reset()`. |
| `submitter` | `false \| ReactNode \| (context) => ReactNode` | submit button | Custom footer actions. |
| `className` | `string` | — | Class name on the form element. |

### ProSchemaForm

| Prop | Type | Default | Description |
|---|---|---|---|
| `schema` | `Array<{ name: string; valueType?: string; ... }>` | — | Field definitions rendered with ProFields. |
| `defaultValues` | `T` | — | Initial field values keyed by schema `name`. |
| `children` | `ReactNode` | — | Extra custom content rendered after generated fields. |

### ModalForm / DrawerForm

| Prop | Type | Default | Description |
|---|---|---|---|
| `schema` | `Array<{ name: string; valueType?: string; ... }>` | — | Optional generated fields rendered before `children`. |
| `formRef` | `Ref<ProFormInstance<T>>` | — | Imperative access to the internal form instance. |
| `validator` | `FormValidateOrFn<T>` | — | TanStack Form submit validator; accepts Standard Schema directly. |
| `defaultValues` | `T` | — | Initial values used by generated schema fields. |
| `children` | `ReactNode` | — | Custom composed form body. |

### FormItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `ReactNode` | — | Field label. |
| `required` | `boolean` | — | Shows the required mark and composes required validation with `validators.onSubmit`. |
| `disabled` | `boolean` | — | Disables the bound child control and applies disabled field styling. |
| `validators` | `ProFieldValidators` | — | TanStack Form field validators for change, blur, or submit. |
| `htmlFor` | `string` | — | Associates label with a field id. |
| `description` | `ReactNode` | — | Label tooltip content. |
| `tooltip` | `ReactNode` | — | Explicit tooltip content. |
| `errors` | `string[]` | `[]` | Error messages rendered below the field and reflected through `aria-invalid`. |
| `extra` | `ReactNode` | — | Helper content rendered below errors. |
