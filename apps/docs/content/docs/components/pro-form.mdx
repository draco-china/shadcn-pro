## Usage

```tsx
import { ProSchemaForm } from "@/components/pro/form"

const roleOptions = [
  { label: "Admin", value: "admin" },
  { label: "Editor", value: "editor" },
  { label: "Viewer", value: "viewer" },
]

export function AccountForm() {
  return (
    <ProSchemaForm
      onFinish={async (values) => console.log(values)}
      schema={[
        { name: "name", label: "Name", required: true, fieldProps: { placeholder: "Alice Wang" } },
        {
          name: "email",
          label: "Email",
          valueType: "email",
          required: true,
          fieldProps: { placeholder: "alice@example.com" },
        },
        {
          name: "role",
          label: "Role",
          valueType: "select",
          fieldProps: { placeholder: "Select role", options: roleOptions },
        },
      ]}
    />
  )
}
```

`ProSchemaForm` is a lightweight mapping layer over `ProForm`, `FormItem`, and ProFields. It keeps field state locally, writes hidden form values for submit, and does not introduce a validation or linkage engine.

Use `ProForm` with `FormItem` directly when the layout needs custom composition.

## Submitter

The default submitter renders a submit button. Pass `submitter={false}` to hide it, or pass a React node / render function when the footer needs custom buttons.

```tsx
import { ProButton } from "@/components/pro/base/button"

<ProForm
  submitter={({ submitting, reset }) => (
    <>
      <ProButton type="button" variant="secondary" disabled={submitting} onClick={reset}>
        Reset
      </ProButton>
      <ProButton type="submit" loading={submitting} disabled={submitting}>
        {submitting ? "Submitting..." : "Submit"}
      </ProButton>
    </>
  )}
/>
```

## ModalForm

<ComponentPreview name="pro-form-modal-demo" />

`ModalForm` wraps the same composed form body in a Dialog and closes after `onFinish` resolves. It also accepts the same `schema` and `initialValues` props as `ProSchemaForm`.

## DrawerForm

<ComponentPreview name="pro-form-drawer-demo" />

`DrawerForm` uses the same API as `ModalForm` and supports `side="top" | "right" | "bottom" | "left"`.

## API

### ProForm

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | — | Form fields and layout sections. |
| `onFinish` | `(values) => void \| Promise<void>` | — | Called with collected `FormData` values. |
| `onFinishFailed` | `(error) => void` | — | Called when `onFinish` throws. |
| `onReset` | `() => void \| Promise<void>` | — | Called after native form reset. |
| `submitter` | `false \| ReactNode \| (context) => ReactNode` | submit button | Custom footer actions. |
| `className` | `string` | — | Class name on the form element. |

### ProSchemaForm

| Prop | Type | Default | Description |
|---|---|---|---|
| `schema` | `Array<{ name: string; valueType?: string; ... }>` | — | Field definitions rendered with ProFields. |
| `initialValues` | `Record<string, unknown>` | — | Initial field values keyed by schema `name`. |
| `children` | `ReactNode` | — | Extra custom content rendered after generated fields. |

### ModalForm / DrawerForm

| Prop | Type | Default | Description |
|---|---|---|---|
| `schema` | `Array<{ name: string; valueType?: string; ... }>` | — | Optional generated fields rendered before `children`. |
| `initialValues` | `Record<string, unknown>` | — | Initial values used by generated schema fields. |
| `children` | `ReactNode` | — | Custom composed form body. |

### FormItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `ReactNode` | — | Field label. |
| `required` | `boolean` | — | Shows the required mark. |
| `htmlFor` | `string` | — | Associates label with a field id. |
| `description` | `ReactNode` | — | Label tooltip content. |
| `tooltip` | `ReactNode` | — | Explicit tooltip content. |
| `errors` | `string[]` | `[]` | Error messages rendered below the field. |
| `extra` | `ReactNode` | — | Helper content rendered below errors. |
